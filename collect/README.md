# "모두의 선택" 연결하기 (약 5분)

플래너는 GitHub Pages라서 스스로 데이터를 저장할 곳이 없다. 내 구글 시트를 저장소로 붙이면, 누가 "저장"을 누를 때마다 시트에 한 줄씩 쌓이고 플래너의 **저장·공유 → 모두의 선택** 표에 사람별 선택이 모여 보인다.

## 순서

1. 브라우저에서 `sheets.new` 를 열어 새 구글 시트를 만든다. 이름은 `제주 동선 모음` 처럼 아무거나.
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 왼쪽 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs) 내용을 통째로 붙여 넣고 저장(디스크 아이콘)한다.
4. 오른쪽 위 **배포 → 새 배포** 를 누른다.
   - 톱니바퀴(유형 선택) → **웹 앱**
   - 설명: `제주 선택 모음`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** 를 누르면 권한 확인 창이 뜬다. 내 구글 계정을 고르고 허용한다.
   "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동** 을 누른다. 내가 방금 만든 스크립트라서 나오는 안내다.
6. 마지막 화면의 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사한다.
7. 그 URL을 플래너 저장소의 `config.js` 에 넣는다 (Claude에게 URL을 주면 대신 넣고 올려 준다).

## 알아둘 것

- 시트에는 저장 시각, 이름, 메모, 점수, 숙소, 포함 체험, 날짜별 일정, 열기 링크가 쌓인다. 잘못 올라간 줄은 시트에서 지우면 된다.
- 플래너 주소가 공개라서 이 URL도 코드에 보인다. 주소를 아는 사람은 이름·메모·선택을 읽고 쓸 수 있으니, 메모에 연락처 같은 개인정보는 적지 말자.
- 나중에 스크립트를 고치면 **배포 → 배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영된다(URL은 그대로).
